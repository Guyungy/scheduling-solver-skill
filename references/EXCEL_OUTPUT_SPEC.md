# Excel 输出规范

正式排班结果默认输出为 `.xlsx`，不能只返回 Markdown 表格或纯文本。

Excel 至少包含以下工作表：

## 1. 排班结果

字段：

- 日期
- 星期
- 节假日/调休
- 早班人员
- 中班人员
- 晚班人员
- 休息人员
- 当日规则状态
- 是否打标

如果某一天存在规则异常、降级、人工例外或待校验项，则该日“是否打标=是”。

## 2. 员工统计

字段：

- 员工姓名
- 早班天数
- 中班天数
- 晚班天数
- 休息天数
- 总出勤天数
- 节假日值班天数
- 晚班规则状态
- 排休规则状态
- 是否打标
- 备注

员工存在少休、超出班次上限、偏好未满足、人工例外或其他规则异常时，“是否打标=是”。

## 3. 规则校验

必须完整列出当前《智能排班规则》记忆中的全部规则，包括没有触发的规则。

字段：

- 规则ID
- 规则名称
- 优先级
- 约束类型
- 是否启用
- 规则值/说明
- 是否命中
- 校验状态
- 是否打标
- 打标类型
- 影响对象
- 说明

### 校验状态

允许值：

- 通过
- 违规
- 已降级
- 部分满足
- 未触发
- 未配置
- 未校验
- 未完整校验
- 人工例外

### 是否打标

以下情况必须打标为“是”：

1. 规则违规
2. 规则被降级
3. 规则仅部分满足
4. 已启用规则无法完整校验
5. 管理员人工覆盖规则
6. 某员工因冲突出现欠休、超班、额外补偿等情况

正常通过、未触发且不存在风险的规则可标记为“否”。

### 打标类型

建议使用：

- 违规
- 降级
- 待校验
- 人工例外
- 补偿
- 风险

## 4. 异常与预案

字段：

- 异常ID
- 冲突规则
- 缺口
- 预案
- 调整内容
- 影响规则
- 推荐级别
- 是否采用
- 是否打标
- 备注

出现无解时，至少记录预案一、预案二、预案三。

被采用的妥协方案必须写入本页，并同步反映到“规则校验”和“员工统计”。

## 5. 输出说明

用于解释：

- 打标规则
- 发布状态
- 求解器版本
- Skill 版本
- 排班周期
- 规则版本
- 生成时间

## 发布状态

Excel 最终应给出以下状态之一：

- 可发布
- 有条件可发布
- 不可发布

判断原则：

- P0/P1 硬约束全部通过，且所有打标项已有明确处置，可以标记“可发布”或“有条件可发布”。
- 存在未处理的 P0/P1 硬约束违规时，必须标记“不可发布”。

## 颜色建议

- 绿色：通过
- 黄色：降级 / 部分满足
- 红色：违规
- 橙色：待校验
- 蓝色：人工例外

Excel 输出必须优先保证可审计性。管理员应能够从文件中直接回答：

1. 这张班表用了哪些规则？
2. 哪些规则完全满足？
3. 哪些规则被妥协？
4. 哪些员工受到影响？
5. 哪些地方需要人工确认？
